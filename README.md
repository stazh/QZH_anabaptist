# TEI Document Processing Tools

This repository contains two Python scripts for processing TEI (Text Encoding Initiative) XML documents, specifically designed for historical sources from the Staatsarchiv des Kantons Zürich.

## Scripts Overview

### 1. `split_Taeuferquellen_tei.py`
**Purpose**: Splits a large TEI XML file containing multiple documents into individual TEI files.

### 2. `extract_full_tei_headers_to_excel.py`
**Purpose**: Extracts header information from a large unsegmented TEI XML file and exports it to an Excel spreadsheet for analysis and overview.

## Prerequisites

### Python Dependencies
- Python 3.8 or higher
- `lxml` - XML processing library
- `openpyxl` - Excel file manipulation (for the extraction script)
- `pathlib` - File path handling (included in Python standard library)

### Installation
```bash
pip install lxml openpyxl
```

## Script 1: `split_Taeuferquellen_tei.py`

### Description
This script segments a large TEI XML file containing multiple `<div type="document">` elements into individual TEI files. Each document becomes a separate, properly formatted TEI file with complete headers and metadata.

### Key Features
- **Document Segmentation**: Extracts each `<div type="document">` into a separate TEI file
- **Date Normalization**: Converts German date formats (e.g., "1542 Oktober 25") to ISO format (1542-10-25)
- **Source Reference Cleaning**: Normalizes archive references (removes "Vorlage:" prefix, standardizes "StAZH" formatting)
- **Complete TEI Headers**: Generates full TEI headers with manuscript descriptions, publication information, and encoding details
- **Editorial Notes**: Preserves editorial notes in a `<back>` section
- **Smart Filename Generation**: Creates meaningful filenames based on document titles

### Usage
```bash
python split_Taeuferquellen_tei.py <input_xml> <output_directory> [--prefix PREFIX]
```

### Parameters
- `input_xml`: Path to the source TEI XML file
- `output_directory`: Directory where individual TEI files will be created
- `--prefix`: Optional filename prefix (default: "doc")

### Example
```bash
python split_Taeuferquellen_tei.py tvz_taeufer_band_6_tei_250528.xml output --prefix QZH
```

### Output
- Individual TEI XML files named: `{prefix}_{number}_{title}.xml`
- Each file includes:
  - Complete TEI header with metadata
  - XML stylesheet processing instruction
  - Document content in `<body><div>`
  - Editorial notes in `<back>` (if present)

### Data Transformations
| Source Element | Target Location | Transformation |
|----------------|-----------------|----------------|
| `<div type="document">` | Individual TEI file | Split into separate files |
| `<head>` | `<msDesc><head>` | Document title |
| `<div type="original">` | `<msIdentifier><idno>` | Source reference (cleaned) |
| `<div type="source" date="...">` | `<origDate when="...">` | Date normalization |
| `<p>` elements | `<body><div>` | Document content |
| `<note type="editorial">` | `<back><p>` | Editorial annotations |

## Script 2: `extract_full_tei_headers_to_excel.py`

### Description
This script analyzes a large unsegmented TEI XML file and extracts all header information that would be generated by the splitting script. It creates an Excel spreadsheet for easy overview and analysis of all documents.

### Key Features
- **Metadata Extraction**: Pulls all relevant header information from each document
- **Excel Export**: Creates a structured spreadsheet with columns for each data field
- **Batch Analysis**: Processes all documents in a single run
- **Preview Functionality**: Shows what the split operation would produce without actually splitting

### Usage
```bash
python extract_full_tei_headers_to_excel.py <input_xml> <output_xlsx>
```

### Parameters
- `input_xml`: Path to the source TEI XML file
- `output_xlsx`: Path for the output Excel file

### Example
```bash
python extract_full_tei_headers_to_excel.py tvz_taeufer_band_6_tei_250528.xml analysis.xlsx
```

### Output Columns
| Column | Description |
|--------|-------------|
| Nr. | Sequential document number |
| Titel/Head | Document title from `<head>` |
| Vorlage/Idno | Source reference (cleaned) |
| Datum (origDate) | Normalized ISO date |
| Transkript (Personen) | Transcription attribution |
| Tagging (Personen) | Tagging attribution |
| Publisher | Publication information |
| Serien-ID | Series identifier |
| Serientitel | Series title |

## Input File Requirements

### Expected TEI Structure
```xml
<TEI xmlns="http://www.tei-c.org/ns/1.0">
  <!-- Multiple document divisions -->
  <div type="document">
    <head>Document Title</head>
    <div type="source" date="1542 Oktober 25">
      <!-- Source information -->
    </div>
    <div type="original">
      Vorlage: StAZH, Archive Reference
    </div>
    <p>Document content...</p>
    <note type="editorial">Editorial note...</note>
  </div>
  <!-- More documents... -->
</TEI>
```

### Date Format Support
The scripts recognize various German date formats:
- `1542 Oktober 25` → `1542-10-25`
- `25 Oktober 1542` → `1542-10-25`
- `1542 Oktober` → `1542-10-01`
- Month name variations: März/Maerz, Dezember/December, etc.

## Generated TEI Header Structure

Each split TEI file includes a complete header with:
- **File Description**: Title, responsibility statements, publication info
- **Series Information**: "Quellen zur Zürcher Geschichte" series data
- **Manuscript Description**: Source identification, dating, physical description
- **Encoding Declaration**: References to transcription guidelines
- **Profile Description**: Text classification

## Error Handling

### Common Issues
1. **No documents found**: Check that input file contains `<div type="document">` elements
2. **Date parsing errors**: Non-standard date formats are skipped gracefully
3. **Filename conflicts**: Long titles are automatically truncated to prevent filesystem issues
4. **Missing dependencies**: Install required packages with pip

### Troubleshooting
- Verify input file is valid XML
- Ensure proper TEI namespace usage
- Check file permissions for output directories
- Validate that all required Python packages are installed

## Project Context

These scripts were developed for processing historical sources from the Staatsarchiv des Kantons Zürich, specifically for the "Quellen zur Zürcher Geschichte" project. They handle the specific requirements of Anabaptist source materials with appropriate metadata standards and archival references.
